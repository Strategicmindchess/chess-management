Ensure it is responsive on desktop, tablet and mobile. ● Pause or reduce motion on hover where supported, and respect reduced-motion accessibility settings. ● The strip should include a clickable “Earn with SMC” link that opens the dedicated Referral Program page. Monthly Student Performance Report Card Generator Build an automated monthly report for every active student. The report must combine verified chess game statistics, SMC leaderboard performance, academic/attendance information and personalized coach feedback. 4.1 Automatic Chess Statistics ● Chess.com and Lichess Rapid, Blitz and Classical ratings, wherever connected and available. ● Opening-of-month rating versus end-of-month rating, with rating gain or decline. ● Total games played, wins, losses, draws and win percentage, separately by format where possible. ● White versus Black performance, where the source data supports it. ● Puzzle attempts, puzzles solved and accuracy, where integrated and available. ● Monthly game activity and data-source/last-sync details. Do not combine ratings from different platforms or formats into one unexplained number. Clearly label each rating and its source. Avoid counting the same game twice when data is collected from multiple integrations. 4.2 SMC Leaderboard Statistics ● Monthly leaderboard rank and previous month's rank. ● Total monthly SMC points, using the existing SMC point calculation system. ● Breakdown of points by eligible activity, such as games, puzzles, attendance and participation, according to the configured rules. ● Weekly leaderboard performance and rank movement. ● Comparison against the student's relevant batch or level, where appropriate. 4.3 Academic and Attendance Information ● Classes scheduled and attended; attendance percentage. ● Assignments assigned and completed; completion percentage. ● Test scores and assessment history, where available. ● Topics covered during the month. ● Current syllabus level and progress through that level. 4.4 Coach Monthly Feedback Add a dedicated Monthly Feedback form in the Coach Dashboard for each assigned student. Coaches should submit: ● Overall performance assessment. ● Tactical understanding, positional understanding, opening preparation and endgame knowledge. ● Calculation/visualization and time management. ● Observed strengths and areas requiring improvement. ● Topics covered during the month. ● Recommended training goals for the next month. do not fabricate or estimate unavailable statistics. ● Allow Super Admin to review, approve, publish or return a report for correction. ● After approval, publish the report to the student's dashboard and make the PDF downloadable. ● Store a historical snapshot so previously published reports do not change when live ratings or leaderboard positions later update. ● Support controlled regeneration before publication and an auditable correction process after publication. ● Prevent duplicate monthly reports for the same student and reporting period. 4.7 Student and Parent Access ● Add “My Performance Reports” to the Student Dashboard. ● Students can view the latest report, download the PDF and access previous months' reports. ● Show rating progress, leaderboard movement, coach feedback and next-month goals. ● If a parent/guardian account is linked, allow authorized parent access to the student's reports. 4.8 Super Admin Report Management ● View report generation status for all active students. ● Track missing/pending coach feedback. ● Review, approve, publish or return reports for correction. ● Download individual reports or bulk reports. ● Regenerate drafts when source data is corrected. ● Monitor monthly progress across batches, levels and coaches, with appropriate access controls. 5.
